# 주제 제안 → 선택 → 제작 → 예약

공유 가능한 운영 기준이다. 기존 프로젝트의 사용자 승인과 연결 설정을 우선한다. 봇 토큰·수신자 ID·채널 ID·음성 ID·개인 경로를 이 문서에 복사하지 않는다. 설치는 자동화 등록이나 발송·업로드 승인이 아니다.

## 주제와 제작
- 트렌드 및 기존 채널의 최근 쇼츠·예약 목록을 확인해 중복 없는 10개 주제를 제안한다. 각 후보에 첫 3초 훅, 근거, 채널 연관성, 예상 생성·음성 비용을 적는다. 실제 증가 근거 없이 급상승이라고 표현하지 않는다.
- 사용자가 번호를 고르면 한 편을 제작한다. 선택 대기는 실패가 아니며 임의 선택하거나 유료 생성하지 않는다. 이미 선택한 사용자에게 재확인을 반복하지 않는다.
- 45초, 첫 3초 핵심 동작과 기승전결, 기본 8초 클립 5개. 실제 기준 이미지 첨부 → Flow 360p → 실제 720p 업스케일 저장 → 기존 Hypit/Hyperframes 편집 → 선택한 음성·기존 BGM → 배경 없는 자막 → 생성 썸네일·제목·설명.
- 상단 파란 큰 제목은 넣지 않는다. 하단 자막은 문장 마침표 없이 1080×1920 기준 y=1500–1660 영역에 배치하며, 화면 바닥과 플랫폼 UI를 피한다. 상세 기준은 production.md를 따른다.
- 프레임·음성·자막·길이·전체 디코딩 확인 결과를 DELIVERY.md에 기록한다. 생성 비용은 예상과 실제를 구분한다. 예산을 넘기는 추가 생성은 사용자 선택을 받는다.

## 예약을 승인한 사용자
- 연결된 대상 채널을 확인하고 실제 Studio 게시·예약·초안과 로컬 큐를 대조한다. 같은 작품은 최종본 한 개만 사용하며 기존 초안을 재사용한다.
- 매일 07시 예약을 요청한 경우 사용자의 시간대를 기준으로 현재보다 최소 2시간 뒤인 가장 빠른 빈 07시 슬롯부터 하루 한 편씩 배정한다. 기존 예약은 이동하지 않는다.
- 제목은 100자 이내, 관련 해시태그 1~2개와 #Shorts를 포함한다. 별도 태그에는 직접 관련된 키워드만 넣는다. 생성한 썸네일과 기존 Shorts 재생목록을 적용한다. 플랫폼 UI가 썸네일 적용을 지원하지 않으면 제한을 알리고 완료라고 주장하지 않는다.
- 설명과 대상 연령·합성 콘텐츠 설정은 내용에 맞게 입력한다. 무료 ElevenLabs 생성물의 상업 이용 제한·출처 표시는 별도로 지킨다.
- 저장 후 Studio에서 video_id, 예약 시각, 시간대, 상태를 다시 확인한다. 업로드·예약·실제 공개는 구분한다.

## 선택형 Telegram 운영
- 사용자가 명시적으로 요청하고 봇·수신자·채널 연결을 확인한 경우에만 매일 18시 10개 주제 제안 → 번호 답장 → 한 편 제작 → 다음 빈 날짜 07시 예약을 사용한다. 기존 자동화를 재사용하며 스킬 업데이트 중 새 자동화를 만들거나 메시지를 보내지 않는다.
- 사용자 원문 답장을 당일 제안과 연결한다. 기존 봇이 답장을 수신하면 별도 getUpdates 수신기를 동시에 실행하지 않는다. 연결된 수신 경로가 동작하지 않으면 알리고 선택을 추측하지 않는다.
- 성공한 단계는 message_id, 클립 ID와 실제 파일, video_id와 예약 시각 등 근거로 건너뛴다. 실패·중단 단계만 실패로부터 1시간 이상 지난 후 재시도한다. 응답이 불확실하면 실제 결과부터 확인해 중복 발송·생성·과금·업로드를 막는다.
- 기존 자동화가 답장을 기다릴 때 짧은 주기로 확인하도록 설정되어 있다면 그 방식을 유지한다. 선택 대기에 재촉 알림이나 추가 제작을 하지 않는다. 진행 중인 작업과 중복 시작하지 않는다.
- 제작 확인·예약 확인·완료 알림을 모두 끝낸 경우에만 전체 성공으로 기록한다. 자동화·Telegram·YouTube 연결 성공을 문서만으로 보장하지 않는다.
