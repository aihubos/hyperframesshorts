전체 지시문

이 페이지의 해삼 쇼츠 제작 자료를 사용해 재제작한다. 영상 프롬프트 3개와 썸네일 프롬프트는 실제 생성에 사용한 원문이다. 설명 그래픽은 SVG/GSAP으로 만든다. Flow에서는 Aside 브라우저를 우선 사용하고 백그라운드 제어 지원 여부를 확인한다. 화면을 임의로 점유하거나 다른 브라우저로 조용히 전환하지 않는다. Omni 1.1 Flash / 360p / 9:16 / 6초 / x1을 실제 UI에서 확인한다. 지원하지 않으면 알리고 다른 모델로 바꾸지 않는다. 이미 제공된 영상 원본을 재사용하면 중복 생성하지 않는다.
나레이션은 VoiceStudio VoxCPM2, 승인된 공유 목소리를 사용한다. 새 음성을 생성하면 원본 대비 1.2배속을 한 번 적용한 후 자막과 장면 타이밍을 다시 정렬한다. 기존 42초 완성본은 과거 보정 atempo=0.9를 사용했으므로 기존 타임코드를 새 1.2배속 음성에 그대로 붙이지 않는다. 기존 완성본을 재현하려면 제공된 narration.wav와 자막.srt를 사용한다.
Wanted Sans 굵은 자막과 청록색/노란색 설명 그래픽, 짧은 전환을 사용한다. 음악은 사용자가 제공한 playful WAV를 정상 속도로 반복하고 -28 LUFS 기준으로 낮게 믹싱한다. 음악 원본은 이 페이지에 배포하지 않으므로 별도로 준비한다. 첫 3초 훅을 보존한다. 종별 차이와 재생에 몇 주가 걸릴 수 있다는 한계를 유지한다.
최종 MP4, 썸네일, 대본, 자막, 제작정보, 유튜브 제목·설명을 ~/Projects/Youtube/영상 제목/에 저장한다. 최종 채팅에는 영상·썸네일 링크와 제목·설명 각각의 코드 블록을 제공한다. 요청 없이 YouTube에 업로드하지 않는다.

Aside 우선 / 백그라운드 작업: 완전한 백그라운드 입력·생성·다운로드는 아직 미검증입니다. 연결 상태를 확인하고 작업합니다. 이 페이지는 작업 지시서이며 Aside를 자동 실행하지 않습니다.
